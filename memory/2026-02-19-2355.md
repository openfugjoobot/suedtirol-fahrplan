## Vorteile

| Vorher | Nachher |
|--------|---------|
| Jedes Repo = eigenes Board | Ein Board = alle Repos |
| Context-Switching zwischen Boards | Alles auf einen Blick |
| Manuelle Sync der Phasen | Auto-Aggregation |
| Repo-übergreifende Blockers nicht sichtbar | Cross-Repo Dependencies sichtbar |
